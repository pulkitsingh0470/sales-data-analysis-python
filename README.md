# SalesHub — Premium Sales Intelligence Dashboard

A polished, interactive Streamlit dashboard for a Python Developer internship project.

### Highlights
- Premium responsive UI with animated cards
- Dark analytics sidebar
- KPI executive snapshot
- Daily revenue + 7-day rolling trend
- Monthly revenue chart
- Product performance + product cards
- Regional revenue + AOV analysis
- Searchable transaction explorer
- Filtered CSV export
- Plotly interactive charts
- GitHub + Streamlit Community Cloud ready

### Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

### Streamlit deployment
Repository: your GitHub repository  
Branch: `main`  
Main file: `app.py`

### Tech stack
Python • Pandas • Plotly • Streamlit • CSV • Git/GitHub
